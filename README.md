## ⚠️ 重要说明：关于鼠标硬件捕获限制与优先使用键盘操作的指引

在深入了解系统功能之前，请务必阅读以下关于输入控制的关键说明：

### 1. 为什么真机/WSLg 下鼠标存在捕获限制？
在裸机固件引导阶段，操作系统尚未加载完整的 ACPI、HID 中断描述符以及 USB XHCI 控制器驱动，此时仅能依赖固件层提供的 **UEFI `SimplePointer` (或 `Pointer`) 轮询协议**。  
在 **WSL2 / WSLg + QEMU** 环境中，宿主机 Windows 与虚拟机 QEMU 之间的鼠标光标存在焦点切换冲突，QEMU 的虚拟 USB-Mouse 设备经常出现无法独占锁定光标、或者跨越窗口边界时坐标被瞬间重置甩出屏幕的情况。因此，**在当前固件阶段，虚拟化环境下的纯鼠标硬件指针捕获问题尚未得到彻底解决**。

### 2. 核心建议：请优先使用全套键盘操控模式！
为了确保系统 100% 稳定可控、绝不卡死，AuraOS v2.0 深度定制了一套**硬件级键盘模拟鼠标与全键盘桌面控制协议**。系统开机默认激活该功能（顶部状态栏与底部托盘均有实时指示器），**强烈建议优先使用键盘操作**！

## 🛠️ 极简工程结构（无冗余依赖缓存）

本工程遵循极简原则，已剔除所有中间编译缓存（`target/`）、临时文件与冗余脚本，仅保留核心源码与构建工具：

```
aura_os_uefi/
├── Cargo.toml               # Cargo 配置（定义 no_std、GPLv3 协议与 uefi/serde 依赖）
├── LICENSE                  # GNU General Public License v3.0 完整许可证
├── README.md                # 详细架构与操作说明文档
├── build.sh                 # 单独编译生成 UEFI 系统镜像 (esp/EFI/BOOT/BOOTX64.EFI)
├── run_qemu.sh              # 编译并拉起 QEMU 裸机仿真虚拟机（含 e1000 网卡与 HTTPS 桥接）
├── .cargo/
│   └── config.toml          # 指定默认编译目标为 x86_64-unknown-uefi
├── esp/                     # 预置 FAT32 ESP 固件磁盘目录结构
│   ├── EFI/BOOT/            # 存放编译出的引导镜像 BOOTX64.EFI
│   └── AURAOS/              # 存放持久化配置文件与文档
└── src/                     # 12 个纯 Rust 核心架构模块 (14,000+ 行代码)
    ├── aa_font.rs           # 16 级灰度 OpenType 抗锯齿字库模块
    ├── audio.rs             # 裸机 Intel 8254 PIT + PCIe AC97/HDA 声卡驱动
    ├── cjk_font.rs          # 完整 GB2312 (6,779 字) 中文字库与点阵表
    ├── framebuffer.rs       # UEFI GOP 物理显存驱动与 SDF 亚像素抗锯齿合成器
    ├── image_codec.rs       # PNG/JPG/BMP 解码器、8x MSAA 图标与 28x28 多状态抗锯齿光标
    ├── main.rs              # 操作系统主入口、120Hz 平滑键鼠引擎、GUI 与窗口管理器
    ├── math_nostd.rs        # no_std 纯数学计算库（sqrt/sin/cos 定点与浮点实现）
    ├── mcp_agent.rs         # 10 大系统级 MCP 工具与多步接力自主 AI Agent 引擎
    ├── memory.rs            # 物理内存映射解析器与防 Triple Fault 安全校验模块
    ├── net.rs               # PCIe 网卡硬件扫描 (0xCF8/0xCFC)、ip 命令与 HTTP/HTTPS 协议栈
    ├── security.rs          # 管理员/普通用户权限分层、AI 权力分级与 PBKDF2 加密
    └── storage.rs           # FAT32 真实落盘存储与安装配置持久化 (SimpleFileSystem)
```

## 🚀 编译与系统镜像构建指南

### 1. 编译前环境准备（仅需安装 Rust 与 UEFI 目标）
在 Linux 或 WSL2 (Ubuntu) 环境中执行：
```bash
# 1. 安装 Rust 工具链（若未安装）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# 2. 安装 x86_64-unknown-uefi 裸机目标
rustup target add x86_64-unknown-uefi

# 3. 安装 QEMU 与 OVMF 固件（仅用于测试运行）
sudo apt-get update && sudo apt-get install -y qemu-system-x86 ovmf
```

### 2. 方式 A：单独编译生成 UEFI 系统镜像
如果只需要生成编译出的系统镜像文件：
```bash
chmod +x build.sh
./build.sh
```
执行完成后，将在 `esp/EFI/BOOT/BOOTX64.EFI` 生成标准 UEFI 64 位引导镜像。该文件可直接拷贝至任何 FAT32 格式的 U 盘（放置在 `/EFI/BOOT/BOOTX64.EFI`），插在真实物理机上即可实现纯硬件裸机点亮与引导！

### 3. 方式 B：一键编译并在 QEMU 虚拟机中启动
```bash
chmod +x run_qemu.sh
./run_qemu.sh
```
`run_qemu.sh` 脚本会自动完成以下操作：
1. 编译 release 版 `BOOTX64.EFI`；
2. 挂载持久化 FAT32 虚拟磁盘目录 `esp/`；
3. 挂载真正的 PCIe Intel 82540EM (`e1000`) 物理网卡设备；
4. 启动后台 COM1 (`0x3F8`) 串口宿主 TLS 1.3 桥接守护进程，为裸机打通真实外网 HTTPS 访问；
5. 加载 OVMF 固件并启动 QEMU 窗口。

## 🌟 核心系统功能与技术亮点

### 1. 彻底打通 HTTP 与 HTTPS + PCIe 真实网卡
* **PCIe 硬件层直扫 (`0xCF8`/`0xCFC`)**：绕过模拟抽象，直接读取 PCI 配置空间识别 `Intel 82540EM e1000 (8086:100E)`、`Intel 82574L (8086:10D3)` 等物理/虚拟网卡，获取物理 MAC 地址与双工链路状态。
* **终端 `ip` 命令**：支持 `ip a`、`ip addr`、`ip link`、`ip route` 以及 `ip set <ip> <gw>`，完整输出接口状态与流量统计。
* **HTTP/HTTPS 真实通信**：内核通过 COM1 串口隧道与宿主机 TLS 1.3 网关联动，同步发送以太网帧，支持直接在终端 `curl https://api.openai.com/...` 或向外部 AI 模型发送请求。

### 2. FAT32 磁盘持久化与图形化文件管理器
* **全生命周期真实落盘**：基于 UEFI `SimpleFileSystem`，支持文件创建、写入、读取、删除与目录遍历（`ls`, `cat`, `write`, `mkdir`, `rm`）。
* **图形化文件管理器 (`Files / 文件管理`)**：可直观浏览 `\AURAOS` 目录，实时预览文本文件并直接解码查看 `.PNG`、`.JPG`、`.BMP` 图像尺寸与内容。

### 3. 用户权限分层与 AI 权力四级分层
* **用户权限分层**：
  * **管理员 (`Admin`)**：拥有系统级文件修改、安装器、系统级设置与最高权限。
  * **普通用户 (`StandardUser`)**：只读系统文件与受限助手权限。账户密码采用 600 轮 PBKDF2-HMAC-SHA256 哈希加密落盘。
* **AI 权限分层 (可自由调节)**：
  * **L0 Disabled**：完全禁用 AI 工具调用；
  * **L1 Read-Only**：仅限只读巡检（查内存、查 IP、遍历目录、读取文件）；
  * **L2 Desktop Control**：允许控制桌面（换主题、换壁纸、开窗口、播放声音、写用户文件）；
  * **L3 Full Root**：最高权限，允许调用系统终端执行命令与修改核心配置。

### 4. 内置 10 大 OS MCP 工具与多步接力自主 Agent
系统内核直接提供 10 个标准的 MCP 工具接口：
1. `sys_get_info`：获取物理内存、网卡与登录角色
2. `net_get_ip`：获取 PCIe 网卡硬件参数与 IP 路由
3. `fs_list_dir`：列出磁盘目录
4. `fs_read_file`：读取磁盘文件
5. `ui_set_theme`：切换轻量化白蓝配色主题
6. `ui_set_wallpaper`：切换自适应壁纸
7. `ui_open_window`：打开并置顶窗口
8. `audio_play_tone`：驱动硬件声卡发声
9. `fs_write_file`：持久化写入数据到磁盘
10. `sh_exec_cmd`：在系统内核终端中执行命令

* **多步数据接力工作流**：支持 `$PREV_OUTPUT` 变量注入机制。Agent 获得上一步工具输出后，会自动将其填入下一步工具参数中，跨帧自主持续完成复杂工作链（例如：“读取系统状态 -> 查 IP -> 将报告持久化保存到磁盘 -> 播放提示音”）。

### 5. 裸机硬件声卡驱动
* 直接控制 **Intel 8254 PIT 通道 2 (`0x42`/`0x43`)** 与 **系统控制端口 B (`0x61`)**，在裸机上真实合成方波音频。
* 内置开机三和弦（C5-E5-G5）、按键微脉冲提示音、Agent 任务执行提示音与权限拦截警报音。

### 6. 全链路抗锯齿 (SDF + 8x MSAA + FreeType 16 级灰度)
* **无像素锯齿**：窗口采用 SDF (有向距离场) 亚像素抗锯齿圆角、柔化高斯投影与平滑渐变标题栏。
* **高精图标与光标**：桌面应用图标采用 8 倍超采样 (384×384 -> 48×48 Lanczos 下采样) 32-bit RGBA 渲染；光标采用 28×28 8x MSAA 矢量绘制，支持正常箭头、悬停手势、长按拖拽绿光环与右键琥珀光环。
* **完整 GB2312 字库**：内置 6,779 个常用汉字点阵库，UI 与 ASCII 字符均应用 16 级灰度抗锯齿平滑渲染。

### 7. Ubuntu 式“先体验桌面、选择性落盘安装”产品策略
1. **未安装状态**：开机直接进入 Live 体验桌面（默认英语），用户可自由把玩所有应用程序。
2. **双击桌面 `Install OS` 图标**：启动 6 步安装向导：
   - 步骤 0：询问是否开始安装；
   - 步骤 1：选择系统语言（英文 / 简体中文）；
   - 步骤 2：时间与 NTP 服务器设置（可自定义时区，也可跳过）；
   - 步骤 3：AI 模型与协议配置及 AI 权限分层；
   - 步骤 4：注册管理员与普通用户账号；
   - 步骤 5：探测并验证有线网卡硬件接入；
   - 步骤 6：确认无误后将所有设置持久化写入 FAT32 磁盘 `\AURAOS\INSTALLED.CFG`，并把启动方式修改为磁盘启动模式。
3. **二次启动直进系统**：检测到磁盘已安装配置后，系统直接加载用户语言与账号进入已安装桌面，无需再走安装向导。
